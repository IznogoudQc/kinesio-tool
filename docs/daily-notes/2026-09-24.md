# 2026-09-24 — Kinésio Pulse devient Effet

Livré en v0.9.227.

## Le renommage

L'app web s'appelle maintenant **Effet** et vit à `https://kinesio-effet.fly.dev`.
Côté outil : le bouton de la barre latérale affiche « Effet », la carte de
Paramètres s'intitule « Mot de passe d'Effet », les messages d'erreur et les
commentaires suivent.

Restent **volontairement** inchangés : les clés de réglages (`pulse.url`,
`pulse.password`), les canaux IPC (`pulse:open`…) et les noms de fichiers. Les
renommer effacerait l'URL et le mot de passe déjà enregistrés chez Marie.

## Deux hôtes tolérés

`DEFAULT_PULSE_URL` pointe sur `kinesio-effet.fly.dev`, mais
`PULSE_ALLOWED_HOSTS` contient aussi `kinesio-pulse.fly.dev`. Une installation
qui a l'ancienne adresse enregistrée dans ses réglages serait sinon refusée à
l'ouverture — le bouton cesserait de marcher du jour au lendemain.

## Fins de ligne

`git status` montrait des dizaines de fichiers modifiés pour un renommage de
six : un outil Windows avait réécrit les fichiers en CRLF. Ajout d'un
`.gitattributes` (`* text=auto eol=lf`, binaires marqués `binary`) pour que ça
ne se reproduise plus. `git add --renormalize .` n'a rien changé : le dépôt
était déjà entièrement en LF, seul le working tree avait dérivé.
